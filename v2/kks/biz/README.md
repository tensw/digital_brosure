# biz — 6하원칙 사업 대시보드 (정적 사본)

- `index.html` 화면, `data/state.js` 데이터. 화면은 데이터 파일만 읽어 그린다.
- 이 사본은 읽기 전용이다. 담당자·금액·상태·액션 체크는 Claude 아티팩트 원본에서 고치고 저장한다.
- 갱신 방법: 원본 아티팩트의 `data/state.js`를 받아 이 폴더의 같은 파일에 덮어쓴다. `index.html`은 화면이 바뀔 때만 교체한다.
- 서버는 `v2`를 루트로 서빙하므로 주소는 `/kks/biz/` 이다. 로그인 게이트(`GATED`)에 넣지 않으면 누구나 볼 수 있다.
