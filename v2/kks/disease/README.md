# 성균관대 희귀질환 연구 20년 — 대시보드

- 배포: https://biblo.ai/kks/disease
- 2026-09-17 작성. 성균관대 의과대학과 삼성서울·강북삼성·삼성창원병원의 희귀질환 연구(2006–2025)를 5개 척도(정의·대상 / 규모 / 꾸준함·추이 / 사회 기여 / 후학 양성)와 세계·한국 기준선으로 보여준다. 척도마다 거버닝 메시지 → 6하원칙 → 시각화 → 출처.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 대시보드 단일 파일. 외부 의존은 Google Fonts뿐 |
| `벤치마크_조사_2026-09-17.md` | 기준선 절의 근거: PubMed 직접 집계 표 4개, 세계 문헌 벤치마크, 한국 환자·R&D·인프라, 참고문헌 |
| `data/pubmed_benchmark_queries.py` | PubMed E-utilities 집계 스크립트(API 키 불필요, 약 3분) |
| `data/pubmed_benchmark_2026-09-17.json` | 위 스크립트의 2026-09-17 결과 |

## 수치의 잣대
- 핵심 수치(1,753편, 의대·병원 논문의 2.97%)는 질병관리청 국가관리대상 희귀질환 1,389종의 질환명이 논문 제목·저자키워드에 명시된 논문이다(BIBLO-RIMS 조사 보고 2026-09-16).
- 기준선의 ‰ 수치는 PubMed에서 'rare disease/orphan drug' 문구 또는 MeSH가 붙은 논문의 비중이다. 두 잣대는 서로 직접 비교하지 않는다.
