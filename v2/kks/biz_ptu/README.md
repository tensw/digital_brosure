# biz_ptu — 평택대 통합 사업 대시보드 (정적 사본)

- `index.html` 화면, `data/state.js` 데이터. 화면은 데이터 파일만 읽어 그린다.
- `../biz`(6하원칙 사업 대시보드)를 복제해 평택대학교 한 곳만 남긴 것. 통합 사업 1건이던 카드를 계약 전체 1장 + 과제 8장으로 펼쳤다.
- 고객이 하나라 화면 축을 바꿨다: 상단 필터는 고객 → 상태, 현황판은 「솔루션 × 단계」와 「과제 성격별」(`state.js`의 `matrixCols`, `groups`).
- 상태 값: 완료 · 진행 · 협조 대기 · 미착수 · 전환.
- 원본 자료: `(5주차) 평택대학교 TODO와 7월 진행 계획.pptx`(2026-06-29), `6하원칙_사업관리서.md`(2026-09-12), 일정 수정 메모(2026-09-23: 공문 RPA 10-07 보고, 플립러닝 10-23 보고, 행정 챗봇·KPI A안 판정 10-08, 연구자성과관리는 연구자 데이터 협조 대기).
- 갱신 방법: `data/state.js`를 고치고 `index.html` 안의 인라인 폴백(`window.__STATE__ = window.__STATE__ || {...}`)도 같은 내용으로 맞춘다. 화면 로직은 화면이 바뀔 때만 손댄다.
- 서버(프록시)가 `.js`를 7일 immutable 로 캐시하므로 `index.html`의 `<script src="data/state.js?v=…">` 버전값을 데이터가 바뀔 때마다 새 값(내용 해시)으로 바꿔야 브라우저가 새 데이터를 받는다. 안 바꾸면 처음 본 옛 데이터가 일주일간 남는다.
- 서버는 `v2`를 루트로 서빙하므로 주소는 `/kks/biz_ptu/` 이다. 로그인 게이트(`GATED`)에 넣지 않으면 누구나 볼 수 있다.
