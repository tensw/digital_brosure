# 성균관대 최상위 논문 — 2026판 성과 · 2027판 성과 · 관리 풀

THE 세계대학평가 대응 정적 대시보드. 상단에서 세 화면을 전환한다. 첫 화면은 2027판 성과, 2026판 성과는 참고.

- **2026판 성과** (`#r26`): THE 2025판(2019~2023) → 2026판(2020~2024)에 새로 세계 상위 10%로 든 논문. 창 이동 신규(2024 출판) 신규 편입 유력 609편 · 두 판 공통 등급 상승 유력 108편. 추정판(v0.9), 학술정보관 활동 전 기준선.
- **2027판 성과** (`#rise`): THE 2026판 → 2027판 등급 상승 후보 655편(상승 유력 200편, 추정 v0.9.2) + 홍보 영상(ScholarIn 아카이브)·Pure 효과 점검(집계만).
- **관리 풀** (`#pool`): 2027판 대비 최상위 예비군 250편.

파일: `index.html`(단일 파일, 데이터·보고서 내장) · `report_2526.html` · `report_rise.html` · `report.html`(I815 A4 보고서 웹 게시판) · `data/` · `i815-*` 자산.
값은 스냅샷 기반 추정치이며 THE 지표값이 아니다. 확정은 SciVal THE 모듈 판별 논문 목록 대조로 한다.
