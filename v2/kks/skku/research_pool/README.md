# 성균관대 최상위 논문 — 성과보고서(2026판→2027판 신규 편입) · 관리 풀(2027판 예비군)

THE 2027판 발표(2026-09-30) 대응 정적 대시보드. 상단에서 두 보고서 유형을 전환한다.

- **성과보고서** (`#rise`): THE 2026판(2020~2024 창)과 2027판(2021~2025 창)에 모두 드는 성균관대 논문(2021~2024 출판) 가운데 작년 판엔 세계 상위 10%가 아니었는데 이번 판에 올라선 논문. **추정 보강판(v0.9.1)** — 작년 판 상위 10% 목록(SciVal THE 2026판) 확보 전. 경계 바로 위(백분위 9~10) 후보 655편에 논문별 피인용 추정(2025-05 x → 2026-05 y)으로 상승 유력 200·판단 유보 183·이미 상위 가능성 267 등급을 붙였다.
- **관리 풀** (`#pool`): 2027판 산정 창의 성대 주저자 논문 중 세계 상위 10~15% 구간에서 연도별 FWCI 상위 50편씩(250편)과 상위 10% 경계까지 필요한 추가 피인용.

파일: `index.html`(단일 파일, 데이터·보고서 내장) · `report.html`(관리 풀 보고서, I815 A4) · `report_rise.html`(성과보고서 잠정판) · `data/`(selected_250.csv · boundary.csv · summary.json · rise_list.csv · rise_summary.json) · `i815-*` 보고서 자산.

원천: THE 2027판 전수조사 — 성균관대 주저자 논문 한정 데이터 분석서(2026-09-28), SciVal 2026-09-20 · Scopus 2026-09-28 스냅샷. 값은 근사 추정치이며 THE 지표값이 아니다. 생성 파이프라인은 별도 저장소에서 관리한다.
