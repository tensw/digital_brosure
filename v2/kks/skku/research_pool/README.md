# FWCI 상위 10~15% 구간 — 성균관대 주저자 최상위 예비군 (THE 2027판)

THE 2027판 산정 창(2021~2025년 출판)의 성균관대 주저자(제1·공동제1·교신) 논문 가운데 SciVal 세계 피인용 백분위 11~15(상위 10~15% 구간)에 있는 논문을
연도별 FWCI 상위 50편씩(총 250편) 추리고, 각 논문이 그 연도의 상위 10% 경계 FWCI 에 닿는 데 필요한 추가 피인용 편수를 붙인 정적 대시보드.

- `index.html` — 대시보드(단일 파일, 데이터·보고서 내장). 탭: 개요 → 기준·산식 → 연도별 → 논문 목록 → 역할·소속 → 유의사항·출처 → 데이터 → 보고서
- `report.html` — 보고서 「FWCI 상위 10~15% 구간 연구성과 분석 보고서 (THE 2027판)」 v1.0 웹 게시판(I815 문서표준 A4 쪽나눔본, `i815-*` 자산 사용)
- `data/selected_250.csv` — 수록 250편 · `data/boundary.csv` — 연도별 경계 FWCI · `data/summary.json` — 집계

원천: THE 2027판 전수조사 — 성균관대 주저자 논문 한정 데이터 분석서(2026-09-28), SciVal 2026-09-20 · Scopus 2026-09-28 스냅샷.
값은 근사 추정치이며 THE 지표값이 아니다. 생성 파이프라인(analysis·report·dashboard 조립기)은 별도 저장소에서 관리한다.
