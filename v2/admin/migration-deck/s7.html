전환·종료 작업의 단계별 실행 조건

전환과 구 시스템 종료는 각각 확인하고 각각 승인한다. 외부 회신만으로 검증 완료로 처리하지 않는다.

작성 2026-09-14 · 대상 개발·운영 전원
책임자 선임연구원 김경수
① 전환 전
확인 항목
잔여 항목의 처리 방안(필수 통과 / 조건부 승인 구분) · 외부 연계 시험 · 실제 업무 처리 시험(응답 코드가 아니라 한 건을 끝까지) · 복구 계획 · 이용 부서 안내 여부
② 실행 승인
승인자가 기록하는 것
시험 결과와 미해결 항목을 검토하고 전환 여부, 승인자, 일시, 근거를 기록한다. 착수 미팅 이후 조건이 바뀌었는지 직전에 다시 확인한다
③ 전환 후
관찰
관찰 담당자 · 기간 · 항목 · 중단·복구 기준. 승인된 기준에 해당하면 지정 담당자가 조치하고 즉시 보고. 기준 밖은 대행자를 포함한 판단 담당자에게 결정 요청
④ 구 시스템 종료 전 · 별도 승인
종료가 무엇을 뜻하는지 먼저 정의
잔여 호출(우리 주소를 부르는 바깥) · 대체 업무 경로 · 데이터 보관 · 유지 기간과 계약 조건. 이 네 가지가 확인된 뒤 전환과 별개로 승인한다
논의 질문전환을 멈추거나 이전 상태로 복구해야 한다고 판단할 업무상의 신호는 무엇입니까?
