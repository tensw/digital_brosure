원칙: 사전 확인과 승인을 거쳐 수행한다

아래는 회의에서 채택할 제안이다. 문장 그대로 규정으로 쓴다.

작성 2026-09-14 · 대상 개발·운영 전원
책임자 선임연구원 김경수
신규 기능, 외부 연계 변경, 데이터 구조 변경, 전환 및 종료 작업은 사전 확인과 승인을 거쳐 수행한다. 작업 책임자(선임연구원 김경수)는 서비스와 데이터를 변경하지 않는 사전 조사를 진행하고, 필요한 업무·기술 담당자와 승인자가 참여하는 착수 미팅을 소집한다. 책임자는 작업 범위, 영향, 검증 방법, 단계별 필수조건, 미확인 사항의 담당자와 기한을 지정된 저장소 폴더에 기록하며, 승인자는 해당 단계의 필수조건 충족 여부를 확인하여 진행 또는 보류를 결정한다. 승인 범위나 필수조건에 영향을 주는 변경이 생기면 작업을 중지하고 재승인을 받는다.
전체 절차
신규 기능 · 외부 연계 변경 · 데이터 구조 변경 · 전환 · 종료
착수 미팅 → 보고서 9항목 → 승인 → 작업 → (전환·종료면) 직전 재확인 → 실행 → 관찰 → 완료 보고
간소화 절차
한 화면에 한정되고, 데이터·권한·공통 기능·외부 연계에 영향이 없는 수정
변경 내용 · 영향 확인 · 검증 결과 · 승인 기록의 네 줄만 남긴다. 영향 여부가 불확실하면 전체 절차
긴급 복구
합의한 긴급 기준에 해당하면 사전 미팅 생략
착수 사실과 사유를 즉시 기록·통지한다. 복구 착수 시점부터 24시간 이내 사후 검토. 긴급 기준과 생략 판단자는 9장에서 정한다
논의 질문이 원칙을 현재 업무에 적용할 때 진행이 막히거나 기준이 더 필요한 부분은 무엇입니까?
