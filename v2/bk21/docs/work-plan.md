## 1. 먼저 정정 — 이 보드에는 점수가 없다

계획을 세우기 전에 실측한 결과, 사실관계를 하나 바로잡는다.

보드 좌측의 **「실적순」 정렬은 점수 정렬이 아니다.** 논문 편수 정렬이다.

```js
// build/app.js:65
L.sort(SRT=='name'    ? (a,b)=>a.d.localeCompare(b.d)
      :SRT=='review'  ? (a,b)=>b.review/b.total-a.review/a.total
      :               (a,b)=>b.papers-a.papers);     // ← 'score' 는 여기로 떨어진다
```

교수 레코드 33개 필드를 전수 확인했으나 **환산점수에 해당하는 값이 없다.**

```
sid name nen part pos kind major deg tp y0 y1 lk em jik conf st en
need low nb na np cite sci kci etc main pc sh dp ifavg ifmax
q1 q2 q3 q4 g kids snp scite sg nkid
```

`np`(논문수) · `cite`(피인용) · `q1~q4`(JCR 분위 편수) · `g`(등급별 편수)는 있으나 이것들을 합친 점수는 어디에도 없다.

**따라서 이번 작업은 기존 점수를 SGCPI+로 «고치는» 것이 아니라, 점수를 «처음 만드는» 것이다.** 기존 값과의 비교표는 만들 수 없다. 비교 대상이 없다.

### 3-2. `U`를 가르는 규칙 — 4단계, 순서대로

앞 단계에서 잡히면 뒤로 넘기지 않는다.

```
1단계  DOI 조인
       dev.paper_citation_metric 에 DOI 일치 → IF_PUB_RANK 획득
       → JCR 백분위 계산 → tr 을 S/A/B/C 로 재부여, U 에서 제거
       대상 12,126건 (92.3%)

2단계  게재지명 → 학회 판별
       j 에 proceedings|conference|symposium|workshop|congress 포함
       → tr = 'P' (학회발표) 로 신설 분류
       대상 3,294건 (1단계에서 안 잡힌 것 한정)

3단계  남은 학술지 → 기타 국제논문
       1·2단계에 안 걸린 학술지 형태
       → tr = 'E' (기타 국제논문)

4단계  그래도 남으면 미판정
       → tr = 'U' 유지. 화면에 «미판정»으로 노출한다 (감추지 않는다)
```

**신설 코드 2개.** `P`(학회발표) · `E`(기타 국제논문). 기존 6종을 건드리지 않고 추가한다.

## 4. 저장 값 — 스키마

### 4-1. 논문 레코드

현재 13개 필드에 **6개를 추가**한다. 기존 필드는 건드리지 않는다.

```jsonc
{
  // ── 기존 (13)
  "y":  "2025",              // 게재연도
  "g":  "SCI",               // 대분류 (SCI | KCI | 기타)
  "r":  "공저",               // 역할 5종
  "c":  0,                   // 피인용
  "if": "",                  // Impact Factor (47.4% 만 채워짐)
  "j":  "저널명",
  "t":  "논문 제목",
  "f":  "",                  // 분야
  "pc": 1, "sh": 2, "dp": 0, // 내부 카운터
  "tr": "U",                 // 등재유형 ← 재부여 대상
  "doi":"10.1109/...",

  // ── 신설 (6)
  "gs":  6,                  // int   저널등급 g. 0|2|3|4|5|6
  "gw":  0.5,                // float 역할가중 w. 1 | 0.5
  "sc":  3.0,                // float 환산점수 = gs × gw
  "pct": 4.85,               // float JCR 백분위(%). 이공·의약만. 없으면 null
  "ai":  0,                  // int   0=아님 1=자동 2=회색확인대기
  "air": ""                  // str   적용 규칙명 (근거 추적용)
}
```

`sc`를 저장하는 이유는 화면에서 매번 계산하지 않기 위해서다. 31,076건 × 2,959명을 브라우저에서 돌리면 느리다.

`air`(적용 규칙명)를 남기는 이유는 **왜 AI 논문으로 잡혔는지 되짚기 위해서다.** 판정만 남기고 근거를 버리면 이의제기에 답할 수 없다.

### 4-2. 교수 레코드

현재 33개 필드에 **6개를 추가**한다.

```jsonc
{
  // ── 신설
  "S":     317.5,            // float 환산점수 합계 = Σ sc
  "Sn":    82.5,             // float 환산편수 합계 = Σ gw
  "Sg":    { "6":12, "5":30, "4":88, "3":45, "2":8, "0":156 },
                             // dict  등급별 편수 (0 = 미판정·50% 밖)
  "Srk":   3,                // int   계열 내 순위
  "Sdrk":  1,                // int   학과 내 순위
  "ai":    7                 // int   AI 논문 편수 (ai=1 만. 회색 제외)
}
```

**순위를 두 개 저장한다.** 계열 내 순위는 경영자 화면, 학과 내 순위는 상세 화면에서 쓴다. 대표 지시대로 보는 자리에 따라 묶는 단위가 다르므로 순위도 둘이 필요하다.

### 4-3. 학과 `stats`

```jsonc
{
  // ── 신설
  "S":     4820.5,           // float 소속 교수 환산점수 합
  "Savg":  104.8,            // float 참여교수 1인당 = S / prof
  "Sg":    { "6":297, "5":442, ... },
  "ai":    112,              // int   AI 논문 편수
  "undet": 3099,             // int   미판정 편수 (tr='U' 잔존)
  "conf":  846               // int   학회발표 편수 (tr='P')
}
```

**`undet`을 저장하는 이유.** 미분류가 몇 건 남았는지를 화면에 띄운다. 숫자를 감추면 점수가 낮은 학과가 실력 문제인지 데이터 문제인지 구분할 수 없다.

**학과 비교에는 `S`가 아니라 `Savg`를 쓴다.** 전자전기컴퓨터공학과는 교수 46명, 심리학과는 5명이다. 합계로 줄을 세우면 규모 순위가 나올 뿐이다.

## 5. 수식

### 5-1. 저널등급 `g` — 계열에 따라 표가 갈린다

**인문 · 사회 · 예체능**

```
g = 6   tr ∈ {S, A, B, C}          (SSCI · SCIE · A&HCI)
  = 3   tr = E                      (기타 국제논문)
  = 2   tr = K                      (KCI, 후보 포함)
  = 0   tr ∈ {U, P}                 (미판정 · 학회발표)
```

JCR 순위를 보지 않는다. SCI 계열이면 순위와 무관하게 6점이다.

**이공 · 의약학**

먼저 백분위를 낸다. `IF_PUB_RANK`가 `"순위/전체"` 문자열로 들어 있다.

```
pct = (순위 ÷ 전체) × 100

  예)  "1/141"   → 0.71%
       "5/103"   → 4.85%
       "18/115"  → 15.65%
```

그 값으로 구간을 가른다.

```
g = 6   pct ≤ 5
  = 5   5 < pct ≤ 10
  = 4   10 < pct ≤ 25
  = 3   25 < pct ≤ 50
  = 0   pct > 50  또는 pct 없음
```

**경계는 이상·이하로 고정한다.** `pct = 5.0` 은 6점이다. 부동소수 비교에서 5.000001이 5점으로 떨어지는 일이 없도록 소수 둘째 자리에서 반올림한 뒤 비교한다.

### 5-2. 역할가중 `w`

```
w = 1.0   r ∈ {단독, 제1, 교신, 제1+교신}
  = 0.5   r = 공저
```

**저자 수를 보지 않는다.** 기존 BIBLO 산식 `주도 2/(n+1) · 공동 1/(n+1)` 과 다르다. SGCPI+는 10인 논문과 2인 논문을 같게 본다.

### 5-3. 논문 환산점수

```
sc = g × w
```

가능한 값은 이 열 가지뿐이다.

| g | w=1 (주저자) | w=0.5 (공저자) |
|---:|---:|---:|
| 6 | 6.0 | 3.0 |
| 5 | 5.0 | 2.5 |
| 4 | 4.0 | 2.0 |
| 3 | 3.0 | 1.5 |
| 2 | 2.0 | 1.0 |
| 0 | 0.0 | 0.0 |

### 5-4. 개인 합계

```
S(인물)  = Σ sc          환산점수
Sn(인물) = Σ w           환산편수
```

**둘 다 낸다.** 환산점수는 질을 반영하고, 환산편수는 양을 반영한다. SGCPI+가 두 값을 따로 요구한다.

### 5-5. 학과 · 계열 집계

```
S(학과)    = Σ S(소속 교수)
Savg(학과) = S(학과) ÷ prof(참여교수 수)

S(계열)    = Σ S(학과 ∈ 계열)
Savg(계열) = S(계열) ÷ Σ prof(학과 ∈ 계열)
```

**대학원생은 합계에 넣지 않는다.** 교수 레코드의 `kids`(지도학생) 실적은 `snp`·`scite`·`sg` 로 따로 붙어 있다. 섞으면 한 논문이 지도교수와 학생 양쪽에서 세어져 이중계상이 된다.

### 5-6. AI 논문 — 환산점수와 섞지 않는다

```
A(인물) = |{ 논문 : ai = 1 }|      1편 1점 고정
```

등급도 역할도 보지 않는다. 그리고 **환산점수 `S`에 더하지 않는다.** 같은 논문이 학술지 점수로 이미 세어졌기 때문에 더하면 이중계상이다. 화면에 **별도 칸**으로 세운다.

회색(`ai=2`) 108건은 A에 넣지 않는다. 사람이 확인한 뒤 `ai=1`로 올린다.

## 6. 작업 순서

화면보다 데이터가 먼저다. 화면부터 만들면 빈 그릇이 된다.

| # | 단계 | 대상 | 산출 |

**1번이 가장 앞의 병목이다.** 이걸 안 하면 이공계 논문 47%가 0점으로 남는다. 2~9번을 다 해도 결과가 틀린다.

### ③ SKKU BK21 성과관리 (`tree`) — 개인 화면

- **개인 소속 표기.** 계열이 아니라 `major`(소속 그룹)와 학과. 개인 창에서만.
- **논문별 산출 내역.** 한 줄에 `tr` · `gs` · 역할 · `gw` · `sc`. 지금은 합계도 없고 내역도 없다. 교수가 「내 점수가 왜 이 값인가」를 물으면 답할 근거가 여기 있어야 한다.
- **AI 논문 배지.** `ai=1` 에 표시. `air`(규칙명)를 툴팁으로.
- **학과 내 순위 `Sdrk`.**

### ⑦ 데이터풀 (`pool`) — 없는 것을 드러낸다

「이 수치의 근거」 아래에 붙인다.

- **미판정 잔존 건수** — 4단계를 거치고도 남은 것. 학과별 `undet`.
- **학회발표 건수** — `tr='P'`. SGCPI+ 표에 자리가 없어 0점 처리된 것.
- **IF 커버리지** — 현재 47.4%, 1단계 후 예상치.
- **SGCPI+가 요구하나 원천이 없는 항목** 목록.

### ① 대학별 성과표 (`sheet`)

SGCPI+ 환산점수 열을 추가한다. **성균관대 열에만 값이 들어간다.** 타 대학은 이 기준으로 계산할 원천이 없다. 빈칸으로 둔다. 없는 값을 0으로 채우면 비교표가 거짓말이 된다.

### ⑤⑥⑧ 관계망 · 탐색

이번 범위 밖. 손대지 않는다.

## 9. 아직 안 정한 것

**하나 — JCR 50% 밖 논문.** SGCPI+ 표는 상위 50%까지만 있다. 그 밖은 0점인지, 표에 없을 뿐 다른 처리가 있는지 학교 확인이 필요하다. **잠정 0점**으로 두되 화면에 편수를 노출한다. 전체의 22.8%에 해당하므로 결정이 바뀌면 점수가 크게 움직인다.

**둘 — 이공계 KCI 논문.** 이공·의약 표에 KCI 자리가 없다. 4,181건 중 이공계 몫을 어떻게 볼지 미정. **잠정 0점**, 편수 노출.

**셋 — 학회발표(`tr='P'`) 3,294건.** SGCPI+ 표에 없다. 잠정 0점.

**넷 — 학기 단위 집계.** SGCPI+는 학기(1학기 3~8월 · 2학기 9~2월)로 끊고 보드는 연도로 끊는다. 온라인 선공개와 정식 게재 날짜가 갈리는 건이 많아 매핑이 간단하지 않다. **연도 유지**로 가고 학교가 요구하면 붙인다.

**다섯 — AI를 소재로 다룬 법학·정책 논문.** 규칙상 잡히지만 「AI 연구 실적」으로 셀지는 학교 판단이다. 회색(108건)으로 빼두고 사람이 본다.

위 세 개(50% 밖 · 이공 KCI · 학회발표)를 다 0점으로 두면 **논문의 상당 부분이 0점이 된다.** 학교와 확인할 때 세 개를 한 번에 물어야 한다. 하나씩 물으면 답이 오는 사이 기준이 또 흔들린다.
