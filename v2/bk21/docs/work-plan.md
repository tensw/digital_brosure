## 1. 먼저 정정 — 이 보드에는 점수가 없다

계획을 세우기 전에 실측한 결과, 사실관계를 하나 바로잡는다.

보드 좌측의 **「실적순」 정렬은 점수 정렬이 아니다.** 논문 편수 정렬이다.

```js
// build/app.js:65
L.sort(SRT=='name'    ? (a,b)=>a.d.localeCompare(b.d)
      :SRT=='review'  ? (a,b)=>b.review/b.total-a.review/a.total
      :               (a,b)=>b.papers-a.papers);     // ← 'score' 는 여기로 떨어진다
```

교수 레코드 33개 필드를 전수 확인했으나 **환산점수에 해당하는 값이 없다.**

```
sid name nen part pos kind major deg tp y0 y1 lk em jik conf st en
need low nb na np cite sci kci etc main pc sh dp ifavg ifmax
q1 q2 q3 q4 g kids snp scite sg nkid
```

`np`(논문수) · `cite`(피인용) · `q1~q4`(JCR 분위 편수) · `g`(등급별 편수)는 있으나 이것들을 합친 점수는 어디에도 없다.

**따라서 이번 작업은 기존 점수를 SGCPI+로 «고치는» 것이 아니라, 점수를 «처음 만드는» 것이다.** 기존 값과의 비교표는 만들 수 없다. 비교 대상이 없다.

### 3-2. `U`를 가르는 규칙 — 4단계, 순서대로

앞 단계에서 잡히면 뒤로 넘기지 않는다.

```
1단계  DOI 조인
       dev.paper_citation_metric 에 DOI 일치 → IF_PUB_RANK 획득
       → JCR 백분위 계산 → tr 을 S/A/B/C 로 재부여, U 에서 제거
       대상 12,126건 (92.3%)

2단계  게재지명 → 학회 판별
       j 에 proceedings|conference|symposium|workshop|congress 포함
       → tr = 'P' (학회발표) 로 신설 분류
       대상 3,294건 (1단계에서 안 잡힌 것 한정)

3단계  남은 학술지 → 기타 국제논문
       1·2단계에 안 걸린 학술지 형태

4단계  그래도 남으면 미판정
       → tr = 'U' 유지. 화면에 «미판정»으로 노출한다 (감추지 않는다)
```

## 5. 수식

### 5-1. 저널등급 `g` — 계열에 따라 표가 갈린다

**인문 · 사회 · 예체능**

```
g = 6   tr ∈ {S, A, B, C}          (SSCI · SCIE · A&HCI)
  = 3   tr = E                      (기타 국제논문)
  = 2   tr = K                      (KCI, 후보 포함)
  = 0   tr = U                      (미판정)
  = 제외 tr = P                     (학회발표 → §5-7)
```

JCR 순위를 보지 않는다. SCI 계열이면 순위와 무관하게 6점이다.

**이공 · 의약학**

먼저 백분위를 낸다. `IF_PUB_RANK`가 `"순위/전체"` 문자열로 들어 있다.

```
pct = (순위 ÷ 전체) × 100

  예)  "1/141"   → 0.71%
       "5/103"   → 4.85%
       "18/115"  → 15.65%
```

그 값으로 구간을 가른다.

```
g = 6   pct ≤ 5                    ┐
  = 5   5 < pct ≤ 10                │ SGCPI+ 표 그대로
  = 4   10 < pct ≤ 25               │
  = 3   25 < pct ≤ 50              ┘
  = 2   pct > 50                    ← 우리 기준 (§5-1-1)
  = 3   tr = E                      ← 우리 기준 (§5-1-2)
  = 2   tr = K                      ← 우리 기준 (§5-1-2)
  = 0   tr = U                      (미판정)
  = 제외 tr = P                     (학회발표 → §5-7)
```

**경계는 이상·이하로 고정한다.** `pct = 5.0` 은 6점이다. 부동소수 비교에서 5.000001이 5점으로 떨어지는 일이 없도록 소수 둘째 자리에서 반올림한 뒤 비교한다.

#### 5-1-1. JCR 50% 밖은 2점 (우리 기준)

SGCPI+ 표는 상위 50%까지만 있다. 그 아래를 0점으로 두면 **같은 SCIE 논문이 계열에 따라 6점과 0점으로 갈린다.** 인문사회는 SCIE면 순위와 무관하게 6점을 주는데, 이공계는 51%라는 이유로 없는 실적이 된다.

**50% 밖 SCI 저널에 2점을 준다.** 최하 구간(50% 이내 = 3점)의 한 단계 아래이자 KCI와 같은 값이다. 등급이 순위에 따라 단조롭게 내려가고, 어느 구간에서도 실적이 사라지지 않는다.

해당 규모는 22.8%다. 0점으로 두면 이 논문들이 통째로 증발한다.

#### 5-1-2. 기타 국제논문 3점 · KCI 2점은 계열 무관 (우리 기준)

이공·의약 표에는 KCI와 기타 국제논문 자리가 없다. 표에 칸이 없다는 것이 실적이 없다는 뜻은 아니다. **실제로 세어 보면 이렇다.**

| 계열 | KCI 편수 | 논문 대비 |
|---|---:|---:|
| 이공 | **1,677** | 8.1% |
| 의약생명 | **1,126** | 14.8% |
| 인문사회 | 1,378 | 47.7% |

**이공·의약생명이 2,803건으로 전체 KCI 4,181건의 67%다.** 표에 칸이 없는 쪽이 오히려 더 많다.

학과별로는 전자전기컴퓨터공학과 643 · 의학과 418 · 약학과 366 · 기계공학과 206 순이다. 게재지는 방송공학회 논문지, 한국전자파학회 논문지, 전기전자재료학회논문지, 신재생에너지 같은 정상 KCI 학술지다.

**인문사회 표의 값을 그대로 가져온다.** 기타 국제논문 3점, KCI 2점. 계열과 무관하게 같은 값이다. 같은 등급의 논문이 계열에 따라 다른 점수를 받을 이유가 없고, 0점으로 두면 두 계열에서 2,803건이 통째로 증발한다.

### 5-2. 역할가중 `w`

```
w = 1.0   r ∈ {단독, 제1, 교신, 제1+교신}
  = 0.5   r = 공저
```

**저자 수를 보지 않는다.** 기존 BIBLO 산식 `주도 2/(n+1) · 공동 1/(n+1)` 과 다르다. SGCPI+는 10인 논문과 2인 논문을 같게 본다.

### 5-3. 논문 환산점수

```
sc = g × w
```

가능한 값은 이 열 가지뿐이다.

| g | w=1 (주저자) | w=0.5 (공저자) |
|---:|---:|---:|
| 6 | 6.0 | 3.0 |
| 5 | 5.0 | 2.5 |
| 4 | 4.0 | 2.0 |
| 3 | 3.0 | 1.5 |
| 2 | 2.0 | 1.0 |
| 1 | 1.0 | 0.5 |
| 0 | 0.0 | 0.0 |

### 5-4. 개인 합계

```
S(인물)  = Σ sc          환산점수
Sn(인물) = Σ w           환산편수
```

**둘 다 낸다.** 환산점수는 질을 반영하고, 환산편수는 양을 반영한다. SGCPI+가 두 값을 따로 요구한다.

### 5-5. 학과 · 계열 집계

```
S(학과)    = Σ S(소속 교수)
Savg(학과) = S(학과) ÷ prof(참여교수 수)

S(계열)    = Σ S(학과 ∈ 계열)
Savg(계열) = S(계열) ÷ Σ prof(학과 ∈ 계열)
```

**대학원생은 합계에 넣지 않는다.** 교수 레코드의 `kids`(지도학생) 실적은 `snp`·`scite`·`sg` 로 따로 붙어 있다. 섞으면 한 논문이 지도교수와 학생 양쪽에서 세어져 이중계상이 된다.

#### 인물 → 학과 매핑은 `kids`를 재귀로 타야 한다

집계를 짤 때 반드시 걸리는 함정이다. `depts[학과].profs` 와 `unassigned` 만 훑으면 **논문의 26.1%(8,097건 · 인물 1,083명)가 학과에 안 붙는다.** 대학원생이 학과 아래가 아니라 지도교수 레코드의 `kids` 배열 안에 중첩돼 있기 때문이다.

```python
def reg(pr, dept):
    if pr.get('sid'): p2d[pr['sid']] = dept
    for k in (pr.get('kids') or []): reg(k, dept)   # ← 이 줄이 없으면 26% 유실

for dept, v in depts.items():
    for grp in ('profs', 'unassigned'):
        for pr in (v.get(grp) or []): reg(pr, dept)
```

`kids`까지 타면 **31,076건 전부 매핑된다(미매핑 0건).** 학과별·계열별 집계가 맞으려면 이게 먼저다.

### 5-6. AI 논문 — 환산점수와 섞지 않는다

```
A(인물) = |{ 논문 : ai = 1 }|      1편 1점 고정
```

등급도 역할도 보지 않는다. 그리고 **환산점수 `S`에 더하지 않는다.** 같은 논문이 학술지 점수로 이미 세어졌기 때문에 더하면 이중계상이다. 화면에 **별도 칸**으로 세운다.

회색(`ai=2`) 108건은 A에 넣지 않는다. 사람이 확인한 뒤 `ai=1`로 올린다.

### 5-7. 학회발표 — 두 갈래로 가른다 (우리 기준)

SGCPI+ 표에 학회발표 자리가 없다. 그렇다고 0점으로 밀면 안 된다. **실측하면 이유가 분명하다.**

| 계열 | 학회발표 | |
|---|---:|---:|
| 이공 | **2,955** | 89.7% |
| 인문사회 | 213 | 6.5% |
| 의약생명 | 126 | 3.8% |

학과별로는 전자전기컴퓨터공학과 1,124 · 물리학과 341 · 기계공학과 318 순이다. **가장 큰 학과의 주된 산출물이다.**

그리고 이 안에 이런 것들이 들어 있다.

| 편수 | 학회 |
|---:|---|
| 43 | CVPR (IEEE Conference on Computer Vision and Pattern Recognition) |
| 29 | AAAI Conference on Artificial Intelligence |
| 13 | MICRO (Symposium on Microarchitecture) |
| 12 | ICASSP |
| 10 | INTERSPEECH |
| 9 | EMNLP |
| 7 | ICCV |

**CVPR·NeurIPS·AAAI는 게재율이 20~25%로 상위 학술지와 같거나 더 좁다.** 전산·전자 분야에서는 학술지가 아니라 이쪽이 주 발표 무대다. 이걸 0점으로 두면 전자전기컴퓨터공학과의 실적이 통째로 사라진다.

반대로 전부에 같은 점수를 주면 지역 학회 발표가 CVPR과 같아진다. 그것도 틀렸다.

**두 갈래로 가른다.**

```
g = 4   최상위 학회 화이트리스트에 걸림      209건 (6.3%)
  = 1   그 밖의 학회발표                  3,085건 (93.7%)
```

최상위 4점은 JCR 상위 25% 구간과 같은 값이다. 학술지보다 위로 올리지 않되 없는 실적으로 만들지도 않는 자리다.

**화이트리스트** — 게재지명에 아래가 포함되면 최상위로 본다.

```
NeurIPS · Neural Information Processing · CVPR · Computer Vision and Pattern
ICCV · ECCV · ICML · ICLR · AAAI · IJCAI · ACL · EMNLP · NAACL
SIGGRAPH · INTERSPEECH · ICASSP · KDD · WWW · CHI
USENIX · NDSS · OSDI · SOSP · ISCA · MICRO · HPCA · DAC · VLSI
```

**이 목록과 4점이 이 계획에서 조정하기 쉬운 두 개의 손잡이다.** 학과 반응을 보고 목록을 늘리거나 점수를 옮기면 된다. 나머지 수식은 SGCPI+ 표에 묶여 있어 손댈 여지가 없다.

현재 섹션: 「투 트랙 매트릭스」 · 「연구단 내 편차」

**추가**

### ③ SKKU BK21 성과관리 (`tree`) — 개인 화면

- **개인 소속 표기.** 계열이 아니라 `major`(소속 그룹)와 학과. 개인 창에서만.

- **AI 논문 배지.** `ai=1` 에 표시. `air`(규칙명)를 툴팁으로.
- **학과 내 순위 `Sdrk`.**

### ⑦ 데이터풀 (`pool`) — 없는 것을 드러낸다

「이 수치의 근거」 아래에 붙인다.

- **미판정 잔존 건수** — 4단계를 거치고도 남은 것. 학과별 `undet`.
- **학회발표 건수** — `tr='P'`. SGCPI+ 표에 자리가 없어 0점 처리된 것.
- **IF 커버리지** — 현재 47.4%, 1단계 후 예상치.
- **SGCPI+가 요구하나 원천이 없는 항목** 목록.

### ① 대학별 성과표 (`sheet`)

## 9. SGCPI+ 표에 자리가 없는 것 — 우리 기준으로 세웠다

이건 시안이다. 학교에 물어 답을 기다리지 않는다. **표에 칸이 없는 항목은 우리가 기준을 세워 채우고, 근거를 남긴다.**

| 항목 | 규모 | 우리 기준 | 근거 |
|---|---:|---|---|
| JCR 50% 밖 | 22.8% | **2점** | 인문사회는 SCIE면 순위 무관 6점. 이공만 51%라고 0점이면 계열 간 형평이 깨진다. 최하 구간(3점) 한 단계 아래 |
| KCI (이공·의약) | **2,803건** | **2점** | 인문사회 표 값을 그대로. 같은 등급이 계열에 따라 갈릴 이유가 없다 |
| 기타 국제논문 (이공·의약) | — | **3점** | 위와 같음 |
| 최상위 학회 | 209건 | **4점** | CVPR·AAAI 게재율 20~25%. 전산·전자의 주 발표 무대 |
| 그 밖의 학회 | 3,085건 | **1점** | 실적이되 학술지 아래 |
| 미판정 잔존 | 4단계 후 잔여 | **0점 · 편수 노출** | 값이 없는 것을 만들어 내지 않는다. 감추지도 않는다 |

**「없으면 0점」을 기본값으로 쓰지 않았다.** 세 항목을 다 0으로 두면 22.8% + 2,803건 + 3,294건이 한꺼번에 사라진다. 그건 학교 실적이 낮다는 뜻이 아니라 우리 표에 칸이 없다는 뜻일 뿐이다.

**공란으로 남긴 것은 하나다** — 타 대학의 SGCPI+ 환산점수. 계산할 원천이 없다. 0으로 채우면 비교표가 거짓말이 된다(§7 ①).

### 기간 단위 — 연도로 간다

SGCPI+는 학기(1학기 3~8월 · 2학기 9~2월)로 끊고 보드는 연도로 끊는다. **연도를 유지한다.** 온라인 선공개와 정식 게재 날짜가 갈리는 건이 많아 학기 매핑이 자의적이 되고, 경계에 걸린 논문이 어느 학기냐로 순위가 뒤집힌다. 연도는 그 흔들림이 없다.

### AI를 소재로 다룬 법학·정책 논문 — 사람이 훑는다

규칙상 회색으로 잡히는 것이 **108건**이다. 결정을 기다릴 규모가 아니라 한 번 훑으면 끝나는 규모다. 훑어서 `ai=1` 또는 `ai=0`으로 확정한다.

### 조정하기 쉬운 손잡이 세 개

시안을 돌려 보고 반응에 따라 움직일 값은 이것뿐이다. 나머지는 SGCPI+ 표에 묶여 있다.

1. **최상위 학회 화이트리스트** (§5-7) — 목록에 학회를 넣고 뺀다
2. **최상위 학회 점수 4점** — 3~5 사이에서 옮긴다
3. **JCR 50% 밖 2점** — 0~3 사이에서 옮긴다

세 값을 `bk21-src` 상단 상수로 빼 둔다. 재계산 한 번이면 전체가 다시 나온다.
