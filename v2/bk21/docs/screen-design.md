# BK21 보드 화면 설계서

작성 2026-09-01 · 프론트엔드

[`work-plan.md`](./work-plan.md)가 데이터를 다룬다면 이 문서는 **화면**을 다룬다. 붙이면서 설계하지 않기 위해 먼저 쓴다.

---

## 0. 먼저 정정 — 작업계획서에 틀린 것이 셋 있다

화면을 안 열고 데이터만 보고 계획을 세운 탓이다. 실제 화면과 `kpi.json`을 열어 확인한 결과다.

### 정정 ① 계열 집계가 «없다»고 썼는데, 키는 있다

`kpi.json` 에 `gy` 키가 이미 있다. 다만 학과 수만 들어 있다.

```json
"gy": { "인문사회": {"n":12}, "이공": {"n":12}, "의약생명": {"n":4} }
```

**새 키를 만들 게 아니라 이 키를 채우는 것이다.** `work-plan.md` §4-4의 `gyo` 신설 안은 폐기하고 `KPI.gy` 를 확장한다. 화면 코드가 이미 `KPI.gy` 를 읽고 있어 참조 경로가 하나로 유지된다.

### 정정 ② PP(top 10%)가 «없다»고 썼는데, 있다

`score-standard.md` §1에 「PP(top 10%) 없다」고 적었으나 **학과 단위로는 이미 산출돼 있다.**

```
qPp10: 4.9        PP top 10% 비율
qFwAvg: 0.73      FWCI 평균
qFwMed: 0.43      FWCI 중앙값
qJcrQ1: 41.6      JCR Q1 비율
qJcrN: 262        JCR 판정 가능 편수
```

exec 화면 KPI 카드 여섯 번째가 이미 이 값을 그리고 있다. 정확히 쓰면 **논문 한 건마다의 PP 값이 `bk21_tree.json` 에 없는 것**이지, PP 지표 자체가 없는 게 아니다.

### 정정 ③ 미분류 42%의 원인이 `kpi.json` 에 적혀 있다

추측할 필요가 없었다. `meta.note` 에 이렇게 쓰여 있다.

> 저널등급 g는 IF 기반 대리(**JCR 백분위 51개 컬럼이 이번 추출에서 제외됨 · 재추출 가능**)

**추출 단계에서 JCR 백분위 컬럼을 뺐다.** Nature Communications가 미분류로 앉은 이유가 이것이다. 그리고 **재추출 가능**하다고 명시돼 있다. `work-plan.md` §6의 1단계(DOI 조인)는 이 재추출로 대체하는 편이 빠르다.

## 1. 기존 화면에서 읽어낸 설계 원칙

새로 만들지 않는다. 이미 서 있는 것을 따른다.

### 1-1. 디자인 토큰

중립 6단계 + 의미색 7쌍(진한색 `--s-*` / 배경틴트 `--t-*`).

```
중립   --c0 #ffffff  --c1 #f3f7fa  --c2 #e4ebf1
       --c3 #cdd5db  --c4 #8ea3b6  --c5 #4b6382  --c6 #071739
글자   --ink #071739  --ink2 #3c5171  --ink3 #4b6382
강조   --navy #071739  --accent #8a6238
의미색 blue green red amber violet lime teal
       예) --s-green #0f7a55 / --t-green #e2f4ec
```

**신규 색을 만들지 않는다.** 등급 6단계도 이 안에서 배정한다(§3-1).

### 1-2. 재사용할 컴포넌트

| 클래스 | 쓰임 | 비고 |
|---|---|---|
| `.kpis` / `.kpi` | 상단 지표 카드 | 6열 그리드. `--c` 로 좌측 3px 띠 색 지정 |
| `.ecard` | 본문 카드 | `h3` + `.d`(설명) + 내용 |
| `.erow.e2` | 카드 2열 배치 | |
| `.mtx` | 표 | `th` sticky, `min-width:720px` |
| `.dgrid` / `.dbox` | 개인창 지표 박스 | **2열 그리드**. 현재 4개 = 2×2 |
| `.dsec` + `h4` | 개인창 섹션 | |
| `.pill` | 배지 | `.off`(공식) `.prov`(잠정) `.in`(내부) `.px` |

### 1-3. 지켜야 할 기존 정책 — 개인 순위를 만들지 않는다

exec 화면 「조치 대상」 카드에 이렇게 박혀 있다.

> **개인 순위표는 만들지 않으며 학과·전공 단위로만 표시합니다.**

이건 문구가 아니라 설계 결정이다. 학과 단위로만 조치를 걸어 개인을 겨냥하지 않겠다는 것이다.

## 2. 협의 — 개인 순위 `Srk` · `Sdrk`

### 기획자 안

`work-plan.md` §4-2에서 교수 레코드에 `Srk`(계열 내 순위)와 `Sdrk`(학과 내 순위)를 저장하기로 했다. 개인이 자기 위치를 알아야 한다.

### 프론트엔드 선임 — 반대

**기존 정책과 정면 충돌한다.** 화면에 「개인 순위표는 만들지 않는다」고 써 놓고 개인 카드에 「학과 3위」를 띄우면 그 문장이 거짓말이 된다. 둘 중 하나는 내려야 한다.

그리고 순위는 **꼬리에서 잔인해진다.** 46명 학과에서 3위는 정보지만 44위는 통보다. 실적이 낮은 이유는 대개 데이터가 안 붙어서인데(지금 U가 42%다) 그 상태로 등수를 매기면 데이터 문제를 실력 문제로 보이게 만든다.

**대안 — 순위 대신 분위(分位)로.** 「상위 25% 이내」처럼 구간으로 보인다. 자기 위치는 알 수 있고 특정인과 겨루는 모양은 안 나온다. 저장 값도 `Srk:3`(정수 순위)이 아니라 `Spct:22.4`(백분위)로 바꾼다.

### 백엔드 선임 — 조건부 반대

순위는 **재계산 시 통째로 흔들리는 값**이다. 한 사람의 논문 한 건에 등급이 붙으면 그 아래 전원의 순위가 밀린다. 저장해 두면 다음 빌드에서 조용히 어긋난다.

백분위도 같은 문제지만 **변동 폭이 훨씬 작다.** 26위→27위는 눈에 띄지만 22.4%→22.9%는 그렇지 않다.

더 큰 문제는 U 42%다. **지금 등수를 매기면 데이터가 잘 붙은 사람이 위로 간다.** 실력 순위가 아니라 데이터 정비 순위다. §6 순서의 1~5단계를 마치기 전에는 어떤 형태로든 개인 줄세우기를 화면에 올리면 안 된다.

### 기획자 결정

**두 선임 의견을 받는다.**

1. `Srk` · `Sdrk`(정수 순위) **폐기.** `Spct`(학과 내 백분위) 하나만 저장한다.
2. 화면에는 **구간으로만** 표시한다 — 상위 10% / 25% / 50% / 그 밖.
3. **1~5단계 데이터 작업 전에는 이 값을 화면에 띄우지 않는다.** 미판정이 10% 아래로 내려간 뒤 연다.
4. exec의 「개인 순위표는 만들지 않으며」 문장은 **유지한다.** 구간 표시는 순위표가 아니다.

## 3. 화면 설계

### 3-1. 등급 색 배정 (공통)

여섯 등급을 기존 의미색에 배정한다. **한 번 정하면 모든 화면에서 같다.**

| g | 뜻 | 배경 | 글자 |
|---:|---|---|---|
| 6 | JCR 상위 5% · SCI(인문사회) | `--t-violet` | `--s-violet` |
| 5 | 5~10% | `--t-blue` | `--s-blue` |
| 4 | 10~25% · 최상위 학회 | `--t-teal` | `--s-teal` |
| 3 | 25~50% · 기타 국제논문 | `--t-green` | `--s-green` |
| 2 | 50% 밖 · KCI | `--t-lime` | `--s-lime` |
| 1 | 그 밖의 학회 | `--t-amber` | `--s-amber` |
| 0 | 미판정 | `--c1` | `--ink3` |

**빨강(`--s-red`)을 등급에 쓰지 않는다.** 빨강은 이미 경고·개선 우선에 배정돼 있다. 등급 낮음은 경고가 아니다.

미판정 0은 **회색이다.** 색을 주면 낮은 등급처럼 읽힌다. 판정을 못 한 것이지 낮은 게 아니다.

### 3-2. ④ SKKU BK21 KPI (`exec`)

기존 구성(6 KPI 카드 → 신호등 → 투트랙 매트릭스 → 성장률 → 편차 → 조치 대상 → KPI 레지스트리)을 유지하고 **두 곳을 바꾼다.**

#### (가) 상단 배지 교체

```
현재  [잠정 v0.1 · 공식 배점 미확보]        ← .pill.prov
변경  [SGCPI+ 배점 v1.0]                  ← .pill.off (공식)
      [자체 보완 6항]                      ← .pill.in  (누르면 §9 표)
```

**「공식 배점 미확보」는 이제 사실이 아니다.** SGCPI+를 채택했다. 다만 표에 칸이 없어 우리가 세운 기준 6개가 있으므로 그것을 두 번째 배지로 분리해 노출한다. 감추지 않되 본문을 어지럽히지 않는 자리다.

#### (나) SGCPI+ 환산점수 카드 — 신설, 신호등 위

`.ecard` 하나. 계열 3장이 가로로 선다.

```
┌─────────────────────────────────────────────────────────────────┐
│ SGCPI+ 환산점수          [SGCPI+ 배점 v1.0] [자체 보완 6항]      │
│ 저널등급 g × 역할가중 w. 주저자 1 · 공저자 1/2. 계열별 배점표 적용. │
│                                                                 │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐            │
│  │ 이공          │ │ 의약생명      │ │ 인문사회      │            │
│  │ 28,400.0      │ │  9,120.5     │ │  3,204.0     │            │
│  │ 1인당 120.3   │ │ 1인당 106.1  │ │ 1인당  25.8  │            │
│  │ ▉▉▉▉▉▉▊░░     │ │ ▉▉▉▉▉▊░░░    │ │ ▉▉▉░░░░░░    │  ← 등급 띠 │
│  │ 학과 12 · 교수236│ │ 학과 4 · 교수86│ │ 학과 12 · 교수124│         │
│  │ 미판정 9,675 ⚠ │ │ 미판정 2,691  │ │ 미판정 770   │            │
│  └──────────────┘ └──────────────┘ └──────────────┘            │
│  ↓ 카드를 누르면 그 계열 학과가 아래로 펼쳐진다                     │
└─────────────────────────────────────────────────────────────────┘
```

**등급 띠**는 6등급 구성비를 한 줄 누적 막대로 그린다(§3-1 색). 합계 숫자만으로는 «점수가 높다»만 보이고 «무엇으로 높은가»가 안 보인다.

**1인당 값을 합계와 나란히 둔다.** 인문사회 3,204는 이공 28,400의 9분의 1이지만 1인당으로는 25.8 대 120.3이다. 두 값이 같은 카드에 있어야 규모 차이를 실력 차이로 오독하지 않는다.

**미판정 편수를 카드 안에 넣는다.** 접어 두지 않는다. 이공 9,675건이 미판정인 채로 나온 점수라는 사실이 점수와 같은 자리에 있어야 한다. 1,000건을 넘으면 `⚠` 를 붙인다.

**펼침 상태.** 카드를 누르면 아래에 `.mtx` 표가 열린다. 계열 하나만 열리고 다시 누르면 접힌다(아코디언 단일 개방).

```
학과              환산점수    1인당    6   5   4   3   2   1   미판정
전자전기컴퓨터공학과   6,204.0   134.9  297 442 1113 103 643  1124   3,099 ⚠
기계공학과           2,880.5   115.2  ...
```

행을 누르면 `tree` 화면의 해당 학과로 이동한다. **경영자 화면에서 상세로 내려가는 통로는 이 한 줄뿐이다.**

#### (다) JCR 4구간 분포 — 신설, 투트랙 매트릭스 옆

`.erow.e2` 의 한 칸. 기존 「투 트랙 매트릭스」와 나란히 선다.

```
┌────────────────────────────────┐
│ JCR 분야순위 분포               │
│ 이공·의약 계열만. 인문사회는     │
│ 등재유형으로 판정한다.           │
│                                │
│  상위 5%   ▉▉▉▉▉▉▉▉ 9,969      │
│  5~10%    ▉▉▉▉▉▉▉▉ 9,925      │
│  10~25%   ▉▉▉▉▉▉▉▉▉▉▉▉▉ 21,587│
│  25~50%   ▉▉▉▉▉▉▉▉▉▉▉▉ 20,741 │
│  50% 밖    ▉▉▉▉▉▉▉▉▉▉ 18,404   │
│                                │
│ [계열 전체 ▾]  ← 필터           │
└────────────────────────────────┘
```

#### (라) 손대지 않는 것

신호등 · 투트랙 매트릭스 · 성장률 · 편차 · 조치 대상 · KPI 레지스트리. **이번 범위 밖이다.** KPI 레지스트리의 「g·w 산식 미수록」 문구만 SGCPI+ 채택으로 갱신한다.

### 3-3. ③ SKKU BK21 성과관리 (`tree`) — 개인 창

현재 개인 창은 `.dgrid` 2×2 박스 4개(논문 / 총 인용 / SCI·KCI / 평균 IF) 다음에 연도별 논문 · 역할 · 저널 · 상위 인용 순으로 이어진다.

#### (가) 지표 박스 4 → 6

```
┌────────────────┬────────────────┐
│ 논문            │ 총 인용         │
│ 339            │ 3,321          │
├────────────────┼────────────────┤
│ 환산점수 ★신설   │ 환산편수 ★신설   │
│ 317.5          │ 82.5           │
├────────────────┼────────────────┤
│ SCI / KCI       │ 평균 IF         │
│ 264 / 75       │ 4.02           │
└────────────────┴────────────────┘
```

**환산점수를 논문·인용 바로 아래에 둔다.** 맨 위가 아니다. 편수와 인용이 사실이고 환산점수는 우리 기준으로 만든 값이다. 위계를 뒤집지 않는다.

`.dgrid` 가 2열이므로 6개면 3행이 된다. 그리드 변경 없이 들어간다.

#### (나) 등급 구성 띠 — 신설, 박스 바로 아래

```
등급 구성
▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉▉
 6:12  5:30  4:88  3:45  2:8  미판정:156 ⚠
```

미판정이 46%인 사람이 있다. 그 사실이 점수와 같은 화면에 있어야 한다.

#### (다) 논문별 산출 내역 — 신설, 가장 중요한 화면

**지금은 합계도 내역도 없다.** 교수가 「내 점수가 왜 이 값인가」를 물으면 답할 근거가 화면에 없다. 이 표가 그 답이다.

`.dsec` + `.mtx`. 기본 접힘, 「내역 보기」로 편다.

```
논문별 산출 내역                                    [내역 보기 ▾]
┌────┬──────────────────────────┬──────┬────┬──────┬──────┐
│ 연도│ 논문 · 게재지              │ 등급  │ 역할│ 가중 │ 점수 │
├────┼──────────────────────────┼──────┼────┼──────┼──────┤
│2025│ Deep Learning-Based …     │ [6]  │교신 │ 1    │  6.0 │
│    │ Nature Communications     │상위5%│    │      │      │
├────┼──────────────────────────┼──────┼────┼──────┼──────┤
│2025│ Non-local Refinement …    │ [4]  │공저 │ 1/2  │  2.0 │
│    │ CVPR              [학회]  │최상위│    │      │      │
├────┼──────────────────────────┼──────┼────┼──────┼──────┤
│2024│ Surveillance Video …      │ [—]  │공저 │ 1/2  │  0.0 │
│    │ Proc. IMCOM 2025  [미판정]│      │    │      │      │
└────┴──────────────────────────┴──────┴────┴──────┴──────┘
                                          합계  82.5   317.5
```

**등급 칸에 근거를 함께 적는다.** `[6]` 만 있으면 왜 6인지 모른다. 「상위 5%」 「KCI」 「최상위 학회」처럼 판정 근거를 아래 줄에 붙인다.

**미판정 행을 숨기지 않는다.** 점수 0.0으로 표시하고 회색으로 둔다. 빠뜨린 게 아니라 못 매긴 것임이 보여야 이의제기가 우리에게 온다.

**정렬 기본은 점수 내림차순.** 연도순이 아니다. 「내 대표 실적이 무엇으로 잡혔나」가 첫 화면이어야 한다. 연도·등급 정렬은 헤더 클릭으로.

**행 수 제한.** 339편짜리 사람이 있다. 기본 30행 + 「더 보기」. 한 번에 그리면 드로어가 멈춘다.

#### (라) AI 논문 배지

논문 행 제목 옆에 `.pill.px`(보라)로 `AI`. 배지에 마우스를 올리면 `air`(적용 규칙명)가 툴팁으로 뜬다.

지표 박스에는 넣지 않는다. **AI 편수는 환산점수와 다른 축이다.** 같은 박스 줄에 두면 더해지는 값으로 읽힌다. 등급 구성 띠 아래에 한 줄로 적는다.

```
AI 관련 논문 7편  ·  환산점수에는 더하지 않습니다
```

#### (마) 소속 표기

현재 헤더가 `참여교수 · 전자전기컴퓨터공학과 · 교번 195015` 다. 여기에 `major`(연구그룹)를 넣는다.

```
참여교수 · 전자전기컴퓨터공학과 · 지능형반도체그룹 · 교번 195015
```

**계열(이공)은 개인 창에 넣지 않는다.** 계열은 집계 축이지 개인의 소속이 아니다(`score-standard.md` §3).

### 3-4. ⑦ 데이터풀 (`pool`) — 없는 것을 드러낸다

기존 「이 수치의 근거」 카드 아래에 `.ecard` 하나를 붙인다.

```
┌─────────────────────────────────────────────────────────┐
│ 산출에서 빠진 것                                          │
│ 점수가 낮은 것과 판정을 못 한 것은 다릅니다. 아래는 후자입니다.│
│                                                         │
│  미판정 잔존      ████░░░░░░  N건   학과별 ▾              │
│  학회발표         ██░░░░░░░░  3,294건 (최상위 209 제외)   │
│  IF 미보유        █████░░░░░  16,361건 (52.6%)          │
│  타 대학 환산점수  ─           산출 불가 · 공란             │
│                                                         │
│  ⓘ JCR 백분위 51개 컬럼이 추출에서 제외되어 있었습니다.      │
│    재추출로 회수 중입니다.  (kpi.json meta.note)          │
└─────────────────────────────────────────────────────────┘
```

**마지막 줄이 이 카드의 핵심이다.** 미판정이 왜 생겼는지를 적어 두면 「데이터가 부실하다」가 아니라 「추출에서 빠졌고 되찾는 중이다」로 읽힌다. 사실이 그렇다.

「학과별 ▾」을 누르면 `undet` 내림차순 표가 열린다.

### 3-5. ① 대학별 성과표 (`sheet`)

SGCPI+ 환산점수 열을 추가한다. **성균관대 행에만 값이 들어간다.**

```
대학          논문     인용     …    SGCPI+ 환산점수
성균관대      31,076  …            40,724.5
서울대        …       …            —  산출 불가
연세대        …       …            —  산출 불가
```

**빈칸에 `—`와 「산출 불가」를 함께 적는다.** 빈칸만 두면 «아직 안 넣었다»로 읽히고, 0을 넣으면 «0점»으로 읽힌다. 둘 다 틀렸다. 타 대학의 원천이 우리에게 없다는 뜻이다.

열 머리에 `.pill.in` 으로 「성균관대만」을 단다.

## 4. 상태 설계 — 세 가지를 구분해 그린다

숫자 화면에서 가장 자주 뭉개지는 지점이다. **셋을 다르게 그린다.**

| 상태 | 뜻 | 표기 | 색 |
|---|---|---|---|
| **0점** | 판정했고 점수가 0 | `0.0` | `--ink3` |
| **미판정** | 아직 못 매김 | `—` + 「미판정」 | `--c1` 배경 / `--ink3` |
| **산출 불가** | 원천이 없음 | `—` + 「산출 불가」 | 배경 없음 |

**빈칸을 그냥 두지 않는다.** 빈칸은 읽는 사람이 알아서 셋 중 하나로 해석하는데, 그 해석이 대개 틀린다.

## 6. 구현 순서

**데이터가 먼저다.** `work-plan.md` §6의 1~7단계가 끝나야 화면에 그릴 값이 생긴다. 그 다음이 이 순서다.

| # | 작업 | 이유 |
|---|---|---|
| 1 | 등급 색 변수 `--g6`~`--g0` 를 `head.html` 에 추가 | 모든 화면이 참조 |
| 2 | `.gband` · `.gtag` 구현 | 세 화면에서 공용 |
| 3 | `tree` 개인 창 — 지표 박스 6개 + 등급 띠 | 가장 작고, 값 검증이 여기서 된다 |
| 4 | `tree` 개인 창 — 논문별 산출 내역 | 3번 값이 맞는지 여기서 확인 |
| 5 | `exec` — SGCPI+ 카드 + 계열 펼침 | 3·4가 맞아야 집계가 맞다 |
| 6 | `exec` — JCR 분포 · 배지 교체 | |
| 7 | `pool` — 빠진 것 카드 | |
| 8 | `sheet` — 환산점수 열 | |

**3·4번을 5번보다 먼저 한다.** 개인 값이 틀린 채로 계열 카드를 만들면 어디서 틀렸는지 못 찾는다. 개인 → 학과 → 계열 순으로 올라가며 검증한다.

## 7. 검증 — 화면을 눌러서 한다

`work-plan.md` §8의 데이터 검증과 별개로, 화면은 **브라우저로 열어 직접 누른다.**

| # | 확인 | 통과 기준 |
|---|---|---|
| 1 | 계열 카드 3장 클릭 | 각각 펼쳐지고, 다른 하나가 접힌다 |
| 2 | 학과 행 클릭 | `tree` 해당 학과로 이동 |
| 3 | 개인 창 열기 | 지표 6박스 + 등급 띠 + 내역 표 |
| 4 | 논문 339편인 사람 | 30행 + 「더 보기」. 드로어가 멈추지 않는다 |
| 5 | 내역 합계 = 지표 박스 환산점수 | 눈으로 대조 |
| 6 | 미판정 행 | 숨지 않고 회색 `—` 로 보인다 |
| 7 | 다크 테마 | `pool` 은 다크로 열린다. 등급 색이 다크에서 읽히나 |
| 8 | 좁은 화면 | `.erow` 1열로 접히고 표가 가로 스크롤 |

**7번을 빠뜨리기 쉽다.** `boot.js` 의 `DARK_VIEWS` 에 `pool` 이 들어 있어 데이터풀은 다크로 열린다. §3-1의 틴트 색(`--t-*`)은 밝은 바탕 기준이라 다크에서 대비가 무너질 수 있다. 다크용 값을 따로 잡아야 한다.

## 8. 아직 안 그린 것

- **계열 카드의 정렬 기준.** 합계순이면 항상 이공이 앞이다. 1인당순이면 순서가 바뀐다. 시안은 합계순으로 두고 반응을 본다.
- **`exec` 세로 길이.** 카드가 둘 늘어난다. 지금도 스크롤이 긴 화면이라 접기가 필요해질 수 있다.
- **인쇄.** 보고용 출력 요청이 나오면 그때 잡는다.
